## Overview

libft is a general-purpose C library providing a collection of common utility functions designed for reusability and efficiency. It includes implementations for string manipulation, memory operations, data structure management (e.g., ft_lstmap for linked lists, stacks, queues), and error handling. The library is structured to be easily integrated into various C projects, offering both high-level functionality and performance optimizations.
