## Overview

libft is a general-purpose C library providing a collection of common utility functions designed for reusability and efficiency. It includes implementations for string manipulation, memory operations, data structure management (linked lists, stacks, queues), and error handling. The library aims to provide essential building blocks that can be used across various projects.

## Features

- **Memory Management**: Functions for allocating, freeing, and manipulating memory.
- **String Operations**: Utilities for string creation, duplication, concatenation, comparison, and more.
- **Data Structures**: Implementations of linked lists, stacks, and queues to manage dynamic data efficiently.
- **Error Handling**: Tools for reporting and managing errors gracefully.
